## E16-01CD · 2016：min-max 与 body-fat z-score

来源：2016 年扫描卷 · Q1(c-d) / 10 points · PDF p.1

状态：完整；形式：计算 / 推导。

### 本题公式 · Min-max 与 z-score

$x$ 为待转换值，原极值为 $x_{\min},x_{\max}$，目标区间为 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

目标为 $[0,1]$ 时，化为 $x'=(x-x_{\min})/(x_{\max}-x_{\min})$；所有值使用同一组极值。

Z-score 为 $z=(x-\mu)/\mathrm{SD}$，$\mu$ 为该列均值，SD 为采用的标准差；题面给出均值或标准差时直接沿用给定量。

### 原文

Use min-max normalization to transform age 49 to [0,1]. Use z-score normalization to transform body fat 41.2, where the standard deviation of body fat is 9.25.

用最小—最大归一化将年龄 49 映射到 [0,1]。用 z 分数归一化变换体脂率 41.2，已知体脂率标准差为 9.25。

| age | %fat |
| --- | --- |
| 39 | 31.4 |
| 57 | 30.2 |
| 41 | 25.9 |
| 58 | 34.1 |
| 47 | 27.4 |
| 58 | 32.9 |
| 49 | 27.2 |
| 60 | 41.2 |
| 50 | 31.2 |
| 61 | 35.7 |
| 23 | 9.5 |
| 52 | 34.6 |
| 23 | 26.5 |
| 54 | 42.5 |
| 27 | 7.8 |
| 54 | 28.8 |
| 27 | 17.8 |
| 56 | 33.4 |

### 逐步解答

#### 本题公式

Min-max 把原区间中的相对位置映射到目标区间 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

Z-score 用“离均值多少个标准差”表示数据：

$$z=\frac{x-\mu}{\sigma},\qquad \mu=\frac1n\sum_{i=1}^n x_i.$$

#### 2. 年龄 49 的 min-max

年龄列的最小值为 23，最大值为 61；目标区间为 $[0,1]$。

$$x'=\frac{49-23}{61-23}=\frac{26}{38}\approx\boxed{0.684211}.$$

#### 3. 体脂 41.2 的 z-score

体脂共 18 个值，总和为 518.1：

$$\mu=\frac{518.1}{18}=28.783333\ldots.$$

使用题给标准差 $\sigma=9.25$：

$$z=\frac{41.2-28.783333\ldots}{9.25}\approx\boxed{1.342342}.$$

因此 41.2 高于体脂均值约 1.342 个标准差。这里均值由体脂列计算，标准差采用题目给定值。


### English answer pattern

Min-max uses the observed minimum and maximum. Z-score uses the mean and the stated standard deviation.

最小—最大归一化使用观测最小值与最大值。z 分数使用均值和题目给定标准差。

### 知识点与公式总结

- **Min-max**：目标区间为 $[a,b]$ 时，$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a)$；原极值取对应变量的原始数据。
- **Z-score**：$z=(x-\mu)/\sigma$，$\mu$ 为同列均值，$\sigma$ 为采用的标准差；本题体脂均值从该列求出，标准差使用题给 9.25。
- **结果含义**：min-max 表示原区间中的相对位置；z 分数表示距均值多少个标准差，正值表示高于均值。

## E20-02C · 2020：33 的 min-max 归一化

来源：2020 年扫描卷 · Q2(3) / 4 points · PDF p.1

状态：完整；形式：计算 / 推导。

### 本题公式 · Min-max 归一化

$x$ 为待转换值，原极值为 $x_{\min},x_{\max}$，目标区间为 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

目标为 $[0,1]$ 时，化为 $x'=(x-x_{\min})/(x_{\max}-x_{\min})$；所有值使用同一组极值。

### 原文

Use min-max normalization to normalize 33. Use the age data of Question 2.

用最小—最大归一化变换 33。使用第 2 题的年龄数据。

### 逐步解答

#### 1. 确定原区间与公式

按原年龄数据，$x_{\min}=13$、$x_{\max}=70$。映射到 $[0,1]$ 使用

$$x'=\frac{x-x_{\min}}{x_{\max}-x_{\min}}.$$

#### 2. 代入 33

$$x'=\frac{33-13}{70-13}=\frac{20}{57}\approx\boxed{0.350877}.$$

分子 20 是 33 到原最小值的距离，分母 57 是整个取值范围；所以结果表示在该区间中约 35.09% 的相对位置。题目未要求删除离群值，归一化仍采用原最大值 70。


### English answer pattern

Using the original data range gives 20/57, approximately 0.350877.

使用原始数据范围，得到 20/57，约 0.350877。

### 知识点与公式总结

- **Min-max 到 $[0,1]$**：$x'=(x-x_{\min})/(x_{\max}-x_{\min})$；$x$ 为待归一化值，极值取本题原始年龄数据。
- **代入核对**：$x_{\min}=13,x_{\max}=70$，因此 $33\mapsto(33-13)/(70-13)=20/57\approx0.350877$。
- **范围一致**：沿用题目要求的数据范围与同一组极值；原最大值 70 参与本题的尺度确定。

## E17-02 · 2017 简答：三种归一化及利弊

来源：2017 年扫描卷 · Q2 / 6 points · PDF p.1

状态：完整；形式：历年简答。

### 本题公式 · 三种归一化的公式

$x$ 为待转换值，原极值为 $x_{\min},x_{\max}$，目标区间为 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

目标为 $[0,1]$ 时，化为 $x'=(x-x_{\min})/(x_{\max}-x_{\min})$；所有值使用同一组极值。

Z-score 为 $z=(x-\mu)/\mathrm{SD}$，$\mu$ 为该列均值，SD 为采用的标准差；题面给出均值或标准差时直接沿用给定量。

Decimal scaling：$x'=x/10^j$，取使全部 $|x'|<1$ 的最小非负整数 $j$。

### 原文

What is Normalization? Please describe the major Normalization methods and their corresponding pros and cons.

什么是归一化？请描述主要归一化方法及各自的优点和缺点。

### 逐步解答

#### 1. 归一化解决什么问题

归一化（normalization）将数值属性转换到可比较的尺度，减少量纲和数值范围对距离、梯度计算的影响。设 x 为原值，$x_{min},x_{max}$ 为训练数据极值，$\mu,\sigma$ 为训练数据均值与标准差。

#### 2. 三种公式、符号与适用特点

**Min-max：映射到指定范围 $[a,b]$。**

$$x'=a+\frac{x-x_{min}}{x_{max}-x_{min}}(b-a).$$

例：原范围 $[10,50]$，将 30 映到 $[0,1]$，得 $(30-10)/(50-10)=0.5$。它保留原相对位置、输出训练值范围明确；极值变化或离群点会改变尺度，新样本可能超出范围。$x_{min}=x_{max}$ 的常量属性需单独处理。

**Z-score：用标准差作为单位。**

$$z=\frac{x-\mu}{\sigma}.$$

例：$\mu=30,\sigma=5,x=40$，则 $z=2$，表示高于均值两个标准差。它将中心与离散程度标准化，适用于尺度差异大的距离/优化任务；输出范围不固定，均值和标准差受离群值影响。$\sigma=0$ 的属性需单独处理。

**Decimal scaling：按十的幂缩小。**

$$x'=\frac{x}{10^j},\qquad j=\min\{k\in\mathbb Z_{\ge0}:\max_i|x_i|/10^k<1\}.$$

例：最大绝对值为 986，取 $j=3$；$x=123$ 得 $x'=0.123$。计算简单、保留正负号与相对比例；取决于最大绝对值，也不保证单位方差。

#### 3. 标准差采用哪个分母

总体与样本标准差分别为

$$\sigma=\sqrt{\frac1N\sum_i(x_i-\mu)^2},\qquad s=\sqrt{\frac1{n-1}\sum_i(x_i-\bar x)^2}.$$

试题若已经给标准差，直接采用题给值；若要求由样本估计，按题目指定的样本/总体口径计算。归一化参数在训练数据上估计，验证和测试数据沿用同一组参数，这样评价才能反映新数据上的表现。


### English answer pattern

Normalization rescales numeric attributes. Min-max controls a range, z-score centers and scales by dispersion, and decimal scaling moves the decimal point.

归一化重新缩放数值属性。最小—最大方法控制范围，z 分数中心化并按离散程度缩放，小数定标移动小数点。

### 知识点与公式总结

- **Min-max**：$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a)$；$[a,b]$ 为目标范围。保留区间相对位置，尺度受极值影响。
- **Z-score**：$z=(x-\mu)/\sigma$；$\mu,\sigma$ 分别为所用均值、标准差。统一中心和离散尺度，输出范围不固定；均值与标准差受离群值影响。
- **Decimal scaling**：$x'=x/10^j$，$j$ 为使全部 $|x'|<1$ 的最小非负整数。计算简单，缩放程度取决于最大绝对值。
- **使用同一尺度**：训练数据确定归一化参数，验证与测试沿用这些参数。常量列使 min-max 或 z-score 分母为 0，需事先约定单独处理。

## HW1-03C · 当前 HW1：20 个销量的 min-max

来源：当前 HW1 · Q3(c)

### 本题公式 · Min-max 归一化

$x$ 为待转换值，原极值为 $x_{\min},x_{\max}$，目标区间为 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

目标为 $[0,1]$ 时，化为 $x'=(x-x_{\min})/(x_{\max}-x_{\min})$；所有值使用同一组极值。

### 原文

## PPT-PRE40 · 课件 · 五个数的 min-max 与 z-score

来源：当前完整七讲课件 · Preprocessing.pdf · Exercise 1(a–b) · PDF p.40

状态：完整课件练习；形式：课件计算 / 逐步练习。

### 本题公式 · Min-max 与 z-score

$x$ 为待转换值，原极值为 $x_{\min},x_{\max}$，目标区间为 $[a,b]$：

$$x'=a+\frac{x-x_{\min}}{x_{\max}-x_{\min}}(b-a).$$

目标为 $[0,1]$ 时，化为 $x'=(x-x_{\min})/(x_{\max}-x_{\min})$；所有值使用同一组极值。

Z-score 为 $z=(x-\mu)/\mathrm{SD}$，$\mu$ 为该列均值，SD 为采用的标准差；题面给出均值或标准差时直接沿用给定量。

### 原文

Use two methods to normalize the following group of data: 200, 300, 400, 600, 1000.

用两种方法归一化下面这组数据：200、300、400、600、1000。

(a) min-max normalization by setting min=0 and max = 1.

(a) 使用 min-max 归一化，将最小值设为 0、最大值设为 1。

(b) Z-score normalization (mean = 500, standard deviation = 316.2).

(b) 使用 z-score 归一化（均值为 500、标准差为 316.2）。

### 逐步解答

#### 1. 写公式并确认参数

Min-max 将原跨度 800 映射为跨度 1：

$$x'=\frac{x-\min X}{\max X-\min X}(1-0)+0=\frac{x-200}{800}.$$

Z-score 先减均值，再除以标准差，表示“离均值多少个标准差”：

$$z=\frac{x-\mu}{\sigma}=\frac{x-500}{316.2}.$$

#### 2. 逐个代入

| $x$ | $x-200$ | Min-max | $x-500$ | Z-score |
| --- | --- | --- | --- | --- |
| 200 | 0 | 0 | -300 | -0.948767 |
| 300 | 100 | 0.125 | -200 | -0.632511 |
| 400 | 200 | 0.25 | -100 | -0.316256 |
| 600 | 400 | 0.5 | 100 | 0.316256 |
| 1000 | 800 | 1 | 500 | 1.581278 |

#### 3. 结果怎样理解

原最小值映射到 0，原最大值映射到 1；300 位于原跨度的 $100/800=1/8$ 处，因此为 0.125。600 高于均值约 0.316 个标准差。这里按题给标准差 316.2 代入，保留 6 位小数。

### English answer pattern

Min-max outputs are (0,0.125,0.25,0.5,1). Z-scores are approximately (-0.948767,-0.632511,-0.316256,0.316256,1.581278).

Min-max 结果为 (0,0.125,0.25,0.5,1)。Z-score 结果约为 (-0.948767,-0.632511,-0.316256,0.316256,1.581278)。

### 知识点与公式总结

- **Min-max 到 $[0,1]$**：$x'=(x-x_{\min})/(x_{\max}-x_{\min})$。本题原最小值 200、最大值 1000，所以分母为 800。
- **Z-score**：$z=(x-\mu)/\sigma$，其中 $\mu$ 是均值，$\sigma$ 是本题采用的标准差；直接代入题给 $\mu=500$、标准差 316.2。
- **标准差口径**：自行计算时，总体方差分母为 $n$，样本方差分母为 $n-1$，标准差再开平方；题面已给标准差时沿用给定值。
