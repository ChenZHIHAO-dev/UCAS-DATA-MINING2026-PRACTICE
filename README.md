# 国科大数据挖掘 · 期末题型练习

在线练习：**[https://chenzhihao-dev.github.io/UCAS-DATA-MINING2026-PRACTICE/](https://chenzhihao-dev.github.io/UCAS-DATA-MINING2026-PRACTICE/)**

共 **99 个题目条目、20 类题型**，覆盖 2016 / 2017 / 2020 扫描卷、2025 回忆复原、2026 考后七题回忆、当前三次作业及往届作业变式。

英文题面后紧跟对应中文，中文来源题另标明英文译写。解答按小问组织，题后附简短知识点与公式总结；英文作答句也配中文。仓库题的补充解释可单独展开，SQL 对照省略展示排序。84 道相关题前提供可收起的公式对照；信息增益、贝叶斯、反向传播等题按公式、代入、结果展开。推荐题按课件均值修正式统一，余弦列出点积和两个模长，距离题解释距离倒数权重。2025 年缺失数据的补配逐题注明。

网站支持按年份查看往年题、题型／例题切换、搜索筛选、答案折叠、原页图片对照、深浅色切换、手机动态导航、收藏、进度导入导出和打印。学习进度保存在当前浏览器，不需要登录；换设备时可导出／导入进度。公式、字体和脚本均随仓库提供，可离线打开 `index.html`。

原卷对照保留在 `assets/scans/`；完整原卷链接指向已核对的公开来源。本仓库不重复保存原卷 PDF、原始作业文件或同学完整报告。第三方材料和库保留其来源与许可证。

页面为静态 HTML / CSS / JavaScript，GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留静态资源目录。部署后的项目子路径不需要改动资源路径。

`bank.js` 是已发布的题目数据，`questions/` 是可直接阅读的 Markdown。数据编辑与重建脚本随配套私有资料仓库保存。
